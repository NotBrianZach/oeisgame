# Public asset sources (for this Godot port)

This prototype is set up so you can drop in public assets quickly.

## Recommended packs

1. **Kenney UI Pack (CC0)**  
   https://kenney.nl/assets/ui-pack
2. **Kenney Pixel Platformer (CC0)**  
   https://kenney.nl/assets/pixel-platformer
3. **Kenney Tiny Dungeon (CC0)**  
   https://kenney.nl/assets/tiny-dungeon

## How to use

- Download one of the packs above.
- Copy desired `.png` / `.svg` files into `godot/assets/`.
- In Godot, reassign sprites/buttons/backgrounds in `scenes/Main.tscn`.
